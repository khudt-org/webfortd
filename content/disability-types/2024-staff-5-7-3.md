# 다. 행사 기획 및 운영

## 1) 행사 기획

지원인력은 청각장애인교원이 학교 행사를 (방학식, 입학식, 졸업식 등) 주체적으로 기획하는데에 필요한 전반적인 결정을 할 수 있도록 소통을 지원한다. 옆에서 항상 같이 있으며 행사 기획 특성 상 단발적이고 잦은 소통이 발생하며 오해가 생기지 않도록 확실히 청취 후 청각장애인교원의 요청 시 지원한다.

지원인력이 명확하게 청취한다면 청각장애인교원도 명확하게 업무를 진행할 수 있다. 그러나 지원인력이 명확하게 청취하지 않는다면 이는 청각장애인교원의 부족한 업무능력으로 오해받을 수 있다.

| 지원 예시 |
| --- |
| □ 행사 기획과정에서 소통이 잘 지원되고 있는 사례<br>[청각장애인교원이 지원인력에게 들은 내용을 확인하는 상황]<br>청각장애인교원: “방금 A선생님께서 000때문에 ●을 가져다 달라고 한거 맞죠?”<br>지원인력: “네, 맞습니다.”<br>[청각장애인교원이 지원인력의 지원을 받은 후 동료교원과 소통을 하는 상황]<br>A교원: “선생님, 저는 ★를 달라고 했던 것 같아요.”<br>청각장애인교원: “ 그때 000 때문에 ●를 원하셨는데 지금은 ★가 필요하세요?” |

| 지원 예시 |
| --- |
| □ 행사 기획과정에서 소통이 잘 지원되고 있지 않은 사례<br>[청각장애인교원이 지원인력에게 들은 내용을 확인하는 상황]<br>청각장애인교원: “방금 A선생님께서 000때문에 ●을 가져다 달라고 한거 맞죠?”<br>지원인력: “어.. 잘 못들은 것 같습니다. 그냥 갖다드리면 될 것 같습니다.”<br>[청각장애인교원이 지원인력의 지원을 받은 후 동료교원과 소통을 하는 상황]<br>A교원: “선생님, 저는 ★를 달라고 했던 것 같아요.”<br>청각장애인교원: “죄송합니다. 제가 그떄 잘못 들었나봐요. 다시 드릴게요.” |

## 2) 행사 운영

지원인력은 행사 운영 과정에서 청각장애인교원과 이루어지는 소통을 모두 지원한다. 행사 과정에서 계획된 내용과 다르게 진행되는 부분이 있는 경우 바로 청각장애인교원에게 알린다. 또한 행사 과정에서 대본에 없는 내용은 최대한 전달한다.

### □ 행사 운영에서 지원되어야 하는 상황의 예시

| ◦ 진행자의 진행 실수<br>◦ 진행자의 농담<br>◦ 주변의 대화 내용<br>◦ 멀리서 큰 소리로 청각장애인교원을 부르는 소리<br>◦ 영상에 음원이 재생되지 않은 경우 또는 고르지 않은 음원<br>◦ PPT를 진행자의 멘트에 따라 넘겨야 하는 경우 |
