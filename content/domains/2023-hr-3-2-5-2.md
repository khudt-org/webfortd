# (2) 편의시설 지원 내용

◦ 교육기관이 설치하여야 할 편의시설의 종류는 다음과 같음

‥매개시설(주출입구접근로, 장애인전용주차구역, 주출입구높이차제거)

‥내부시설(출입구(문), 복도, 계단 또는 승강기)

‥위생시설(화장실, 욕실, 샤워실ㆍ탈의실)

‥안내시설(점자블록, 유도 및 안내 설비, 경보 및 피난설비)

‥기타시설(객실ㆍ침실, 관람석ㆍ열람석, 접수대ㆍ작업대, 매표소ㆍ판매기ㆍ음료대, 휴게시설)

◦ 이러한 편의시설 유형 중 교육기관이 주로 갖추어야 할 편의시설은 다음과 같음

- 통행이 가능한 접근로, 보행 안전, 장애인 전용 주차구역, 높이 차이가 제거된 건축물 출입구, 강의실 및 기타시설, 통행이 가능한 복도 및 통로, 통행이 가능한 계단, 장애인용 승강기, 장애인용 화장실, 작업대, 피난시설 등

교육기관이 갖추어야 할 주요 편의시설

| 시설 유형 | 확충해야 할 내용 | 관련 사진 |
| --- | --- | --- |
| 통행이 가능한 접근로 | ∙휠체어사용자가 통행할 수 있도록 접근로의 유효폭은 1.2m 이상을 확보해야 하며, 휠체어사용자의 교행이 가능한 폭은 1.8m 이상을 확보해야 함 |  |
| 보행<br>안전 | ∙보행로 바닥은 장애인의 안전을 위하여 잘 미끄러지지 않는 재질로 평탄하게 마감해야 함 |  |
| 장애인<br>전용<br>주차구역 | ∙장애인전용주차구역의 크기는 주차대수 1대에 대하여 폭 3.3m 이상, 길이 5.0m 이상 최소 1면 이상은 의무설치 해야 하고, 장애인전용주차구역은 장애인등의 출입이 가능한 건축물의 출입구 또는 장애인용 승강설비와 가장 가까운 장소에 설치하여야 함 |  |
| 높이<br>차이가 제거된 건축물 출입구 | ∙출입구와 접근로 바닥의 단차는 0.75m 이하로 하고, 전동휠체어가 움직일 수 있도록 1.2m이상의 유효폭 경사로를 설치함. 또한 진입구간은 가급적 별도의 경사로와 계단이 없이 설치하되, 바닥면이 기울어진 경우에는 경사로 1/18 이하로 함 |  |
| 강의실 및 기타시설 | ∙교실 면적은 50㎡ 이상을 갖추어야 함. 또한 출입문 손잡이는 중앙지점이 바닥면으로부터 0.8m와 0.9m 사이 설치, 투시 가능하여 반대편을 볼 수 있게 설치함. 휴게실과 상담실은 1개소 이상 설치하고, 체육실, 체험실, 보건실, 대기실, 자료실, 식당 등은 교육기관의 여건에 따라 선택적으로 설치할 수 있음 |  |
| 통행이 가능한 복도 및 통로 | ∙복도 유효폭은 1.2m 이상으로 하며, 바닥은 높이차가 없도록 하고, 미끄러지지 않는 재료를 사용함. 복도 양 측면에 연속 손잡이를 설치해야 함 |  |
| 통행이 가능한 계단 | ∙계단은 바닥면으로부터 높이 1.8m 이내마다 계단참을 설치하고, 계단 및 참의 유효폭 1.2m이상, 디딤판 너비는 0.28m 이상, 챌면의 높이는 0.18m 이하, 높이 2cm 이상의 추락방지턱을 설치해야 함. 바닥표면은 미끄럼방지설비를 하고, 난간의 높이는 바닥면 기준 1.2m 이상, 계단참 및 계단 마지막 디딤판 부분의 난간 높이는 바닥면 기준 1.5m 이상이어야 함 |  |
| 장애인용 승강기 | ∙장애인용 승강기 전면공간은 1.4m×1.4m 이상의 활동공간을 확보해야 함. 승강장바닥과 승강기바닥의 틈은 3cm 이하, 승강기 호출버튼･조작반･통화장치 등 모든 스위치의 높이는 바닥면으로부터 0.8m 이상 1.2m 이하로 설치되어야 함. 또한 승강기의 바닥면적은 폭 1.6m이상, 깊이 2.3m이상으로 함 |  |
| 장애인용 화장실 | ∙장애인용 화장실 대변기 유효바닥면적은 폭 1.6m 이상, 깊이 2.0m 이상이 되도록 설치해야 하고, 대변기의 전면에는 휠체어가 회전할 수 있도록 1.4m×1.4m 이상의 활동공간을 확보해야 함. 또한 비상용 벨은 대변기 가까운 곳에 바닥면으로부터 0.6m 이상 0.7m 사이의 높이에 설치해야 함<br>∙장애인용 화장실 소변기는 수평손잡이 높이는 바닥면으로부터 0.8m 이상 0.9m 이하, 수직손잡이 높이는 바닥면으로부터 1.1m 이상 1.2m 이하로 설치해야 함<br>∙화장실 세면대의 상단높이는 바닥면으로부터 0.85m, 하단 높이는 0.65m 이상으로 하며, 화장실 거울상단 부분은 15도 정도 앞으로 경사지게 하거나 전면거울을 설치할 수 있음 |  |
| 작업대 | ∙작업대의 전면에는 휠체어를 탄 채 접근이 가능한 활동공간을 확보 |  |
| 피난시설 | ∙비상벨 설비 주변에는 점멸형태의 비상경보등을 함께 설치해야 하고, 긴급 대피공간을 설치해야 함 |  |

◦ 시각장애인 및 청각장애인을 고려하여 다음과 같은 시설, 설비 환경을 갖출 수 있어야 함

- 점형블록, 선형블록, 점자안내판, 촉지도식 안내판, 음성안내장치, 비상벨 설비, 점멸형태의 비상경보등, 피난구유도등, 종소리경광등 등

| 고려해야 할 시설 설비 환경 |
| --- |
| ∙ 시각장애인을 위한 점형블록은 계단･장애인용 승강기･화장실 등이나 시각장애인에게 위험한 장소의 0.3미터 전면, 선형블록이 시작･교차･굴절되는 지점에 이를 설치하여야 함. 선형블록은 대상시설의 주출입구와 연결된 접근로에서 시각장애인을 유도방향에 따라 평행하게 연속해서 설치<br>∙ 시각장애인 유도안내 설비인 점자안내판 또는 촉지도식 안내판에는 주요시설 또는 방의 배치를 점자, 양각면 또는 선으로 간략하게 표시하고, 바닥면으로부터 1.0m 내지 1.2m의 범위안에 있도록 설치함. 또한 시각장애인용 음성안내장치는 주요시설 또는 방의 배치를 음성으로 안내<br>∙ 시각･청각 장애인 경보･피난 설비는 청각장애인을 위하여 비상벨설비 주변에는 점멸형태의 비상경보등을 함께 설치하고, 시각･청각 장애인용 피난구유도등은 화재발생 시 점멸과 동시에 음성으로 출력될 수 있도록 설치하여야 함 |

◦ 이러한 편의시설 설치를 위하여 각급학교에서는 편의시설 설치 여건을 확인하고 미설치 편의시설을 확충할 수 있도록 관련 계획을 수립, 운영하는 등 편의시설 완비를 위하여 노력하여야 함
