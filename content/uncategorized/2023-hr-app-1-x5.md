# □ 중증장애인 확인을 위한 구체적인 장애상태

※ 「중복된 장애의 합산 판정 기준 및 중증장애인 확인 고시」(고용노동부고시) 별표1에 따른 기준

| [별표 4]<br>중증장애인 확인을 위한 구체적인 장애상태<br>1. 지체장애인<br>가. 다리 절단장애(하지 절단장애)<br>나. 다리 관절장애<br>※ 다리의 3대 관절은 엉덩관절, 무릎관절, 발목관절을 말한다.<br>다. 다리 기능장애<br>라. 척추장애<br>2. 청각장애인<br>3. 간장애인<br>4. 안면장애인<br>5. 장루ㆍ요루장애인<br>6. 그 외 지체장애인(상지 절단장애, 상지 관절장애, 상지 기능장애), 뇌병변장애인, 시각장애인, 지적장애인, 정신장애인, 자폐성장애인, 신장장애인, 심장장애인, 호흡기장애인, 뇌전증장애인의 중증장애인 확인은 보건복지부장관이 고시한 「장애정도판정기준」의 ‘장애의 정도가 심한 장애인’ 기준을 따른다. |
| --- |

| 장애 상태 |
| --- |
| 1. 두 다리를 무릎관절 이상 부위에서 잃은 사람<br>2. 두 다리를 발목관절 이상 부위에서 잃은 사람 |

| 장애 상태 |
| --- |
| 1.두 다리의 모든 3대 관절의 운동범위가 각각 75% 이상 감소된 사람<br>2.두 다리 각각의 3대 관절 중 2개의 운동범위가 각각 75% 이상 감소된 사람<br>3.두 다리의 모든 3대 관절의 운동범위가 각각 50% 이상 75% 미만 감소된 사람 |

| 장애 상태 |
| --- |
| 1.두 다리를 완전마비로 각각 전혀 움직일 수 없는 사람(근력등급 0, 1)<br>2.두 다리를 마비로 각각 겨우 움직일 수 있는 사람(근력등급 2) |

| 장애 상태 |
| --- |
| 1. 목뼈와 등·허리뼈의 운동범위가 정상의 4/5 이상 감소된 사람<br>2. 강직성 척추질환으로 목뼈와 등뼈 및 허리뼈가 완전강직된 사람 |

| 장애 상태 |
| --- |
| 1. 두 귀의 청력 손실이 각각 90데시벨(dB) 이상인 사람 |

| 장애 상태 |
| --- |
| 1.만성 간질환(간경변증, 간세포암종 등)으로 진단받은 환자중 잔여 간 기능이 만성 간질환 평가척도(Child- Pugh score) 상 등급 C이면서 최근 6개월 동안 다음의 합병증 중 하나 이상을 보이는 사람<br>1) 간성뇌증 2회 이상, 2) 내과적 치료로 조절되지 않는 난치성 복수, 3) 간신증후군, 4) 정맥류 출혈 2회 이상<br>2.만성 간질환(간경변증, 간세포암종 등)으로 진단받은 환자 중 잔여 간 기능이 만성 간질환 평가척도(Child- Pugh score) 상 등급 C이면서 다음의 병력(2년 이내의 과거병력) 중 하나 이상을 보이는 사람<br>1) 간성뇌증의 병력, 2) 자발성 세균성 복막염의 병력, 3) 간신증후군의 병력, 4) 정맥류 출혈(2회 이상 발생)의 병력 |

| 장애 상태 |
| --- |
| 1. 노출된 안면부의 90% 이상의 변형이 있는 사람<br>2. 노출된 안면부의 60% 이상의 변형이 있고 코 형태의 2/3 이상이 없어진 사람 |

| 장애 상태 |
| --- |
| 1. 장루와 함께 요루 또는 방광루를 가지고 있으며, 그 중 하나 이상의 루에 합병증으로 장피누공 또는 배뇨기능장애가 있는 사람<br>2. 장루 또는 요루를 가지고 있으며, 합병증으로 장피누공과 배뇨기능장애가 모두 있는 사람<br>3. 배변을 위한 말단 공장루를 가지고 있는 사람 |
